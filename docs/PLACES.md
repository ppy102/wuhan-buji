# 地点资料与维护

页面提供三镇分类、地点关键词、适合的出行时段、建议停留时间及两条可选的慢行组合。建议时长是编辑估计，不含往返交通、排队或入馆时间；它不是距离、班次或开放时间的保证。开放入口、馆内预约、票价、店铺营业和交通变化以现场或机构最新信息为准。

## 来源

- [武汉市文化和旅游局：江汉关博物馆](https://wlj.wuhan.gov.cn/zfxxgk/fdzdgknr/jgjj/zsdw/202008/t20200827_1437247.shtml)：江汉关地址为沿江大道 129 号。
- [武汉市自然资源和城乡建设局：汉口江滩规划](https://zrzyhgh.wuhan.gov.cn/gsggzx/ghzs/202007/t20200707_1396436.shtml)：汉口江滩一期以江汉关为起点；页面据此把两处放入一条可选路线，不声称当前开放入口的位置。
- [武汉东湖风景区管理委员会：来东湖请注意](https://www.whdonghu.gov.cn/xwzx_6309/dhyw/202403/t20240315_2373415.shtml)：介绍梨园和磨山入口。页面建议从梨园一带开始，不沿用该报道中的临时交通管制信息。
- [湖北日报：昙华林—粮道街游览建议](https://news.hubeidaily.net/pc/c_3468866.html)：提供昙华林与粮道街的组合及地铁 5 号线昙华林武胜门站信息。
- [武汉市城市管理执法委员会：大成路过早](https://cgw.wuhan.gov.cn/cgdt/cgw_cgxw/202501/t20250106_2513204.shtml)：介绍武昌大成路过早及其街区。
- [武汉市人民政府：武汉赏秋](https://www.wuhan.gov.cn/zjwh/whly/202610/t20261031_2871802.shtml)：提到解放公园和沙湖公园。

以上资料于 2026-11-02 查阅。其余地点沿用项目既有的街区描述；未逐一核实全部地点的当前入口、交通、费用或营业状态。页面不显示未核实的地铁出口、票价、班次和商铺营业时间。

## 更新方式

地点字段在 `src/state.js`，部分场景以 source 指向相关资料；短路线和两个地点入口按钮在 `index.html`。更新地名、起点和线路关联时先核对权威公开资料；把来源及查阅日期补在本文，并保持原有场景 ID 不变，以兼容已保存的收藏。
