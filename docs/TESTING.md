# 测试与验收

## 自动化

`npm test` 使用 Node 自带测试运行器，无测试依赖。

- state.test.mjs：初始状态、去重、错误字段、未知 ID、未知动作、收藏与移出、JSON 往返及四个场景数据。
- storage.test.mjs：版本化键名、存储读写、损坏 JSON、读取被拒、写入配额失败。
- journal-state.test.mjs：撕纸正常路径、空白和长度边界、最近五条、便签快照、空白和长度边界、版本/标签/真实日期校验。
- `npm run build`：12 个 JS 模块语法与 HTML 本地资源路径校验；纯静态站点无需打包。

## 浏览器验收

在隔离浏览器存储中验收，不触碰已有浏览器收藏：
1. 默认声音关；首屏和素材正常，无页面异常或失败请求。
2. 戳泡泡 → 场景卡 → 收藏 → 今天的口袋 → 刷新，状态正确保留。
3. “算了，下次”和 Escape 关闭模态框，焦点返回触发按钮。
4. 移出收藏后泡泡仍为戳破状态；空口袋有说明。
5. 320px、390px、1440px 无水平溢出；减少动态效果时禁用动画和平滑滚动。
6. 主动开启音效后戳新泡泡能完成音频上下文创建和释放，无音频文件请求。
7. 存储损坏或被阻止时可继续操作，页面提示仅临时保留。
8. 原创胖鲸鱼 SVG 双帧图正常加载，宽高比为 2:1，展示窗口不为圆形；点击切至闭眼带 Zzz 的一帧，再点击返回睁眼帧，替代文本同步。截图 companion.png 与 companion-resting.png 覆盖两种状态。
9. 16 个泡泡保留原收藏；章节导航可直接跳转。
10. 四种底噪默认不创建 AudioContext；开始、重复点击、快速切换和全停正常，最多一个环境实例，停止至少淡出一秒，未请求音频文件。
11. 撕纸仅保留最近五条，空白不提交；HTML 形状的输入按纯文本显示；三次互动后可打开与退出金色借口卡。
12. 便签空白不提交、保存后刷新恢复；输入尚未保存时不更改导出快照。实际下载 PNG 为 1080×1350；120 字长文本导出不超出版面。存储被禁用时仍可临时预览并提示。
