# 当前功能与验收边界

## 已完成

- 16 套原创武汉地点线稿与插画，泡泡显示地点与动作，详情卡含区域说明，借口卡覆盖全部地点。
- 地点可按三镇及兴趣组合筛选；详情显示起点与建议时长，口袋可重新打开详情，并提供江汉关—江滩、昙华林—粮道街两条可选短路线。两张实景照片附有来源和许可。

- 首屏、原创胖鲸鱼、16 个泡泡和本地收藏；保留首版四个 ID，手机 4 列、桌面 8 列。
- 撕烦恼：六条预设与自由输入，560ms 撕纸反馈，最近五条回复；减少动态效果时禁用动画。
- 四种环境底噪：Web Audio 合成，默认关闭，同一时间一个，停止与切换时淡出 1.2 秒。
- 便签存根：本地保存文字、日期与随机标签，导出 1080×1350 PNG。
- 金色惊喜：三次新泡泡或撕纸互动后可点击领取借口卡，不展示进度。

## 验证边界

- 自动化使用 Windows Edge；Safari/iOS 的音频解锁与下载体验尚未实机验证。
- 底噪为合成意象，非武汉实地录音，不模拟真实对话。实际听感需在自己的设备上体验。
- 收藏与便签不跨设备同步。无公开留言、地图、预订或 AI 接口。
