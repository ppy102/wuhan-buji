# 武汉不急

## 项目简介
一本可以戳泡泡、和大肥鱼一起歇一会儿的纯前端武汉下午小册子。

## 快速开始
在此目录用本地 Python 启动静态预览，例如 `python -m http.server 4173 --bind 127.0.0.1`，打开 http://127.0.0.1:4173/ 。Python 不在 PATH 时使用项目环境提供的解释器绝对路径。也可使用编辑器的静态服务器。

GitHub Pages：将本目录内容作为站点根目录发布即可，无需安装包、构建服务或密钥。ES Modules 需要 HTTP 访问，请勿直接双击 HTML。

## 功能列表
- 首屏介绍武汉慢游，并直接提供按地区和兴趣选去处、查看小路线的入口；使用本地标题字体和武汉地标线稿。
- 原创武汉江岸 SVG、轮渡与树荫长椅。
- 16 套武汉地点线稿与插画，覆盖汉口、武昌、汉阳的地标、老街、过早街巷与公园；东湖和长江大桥详情卡使用标明作者和许可的本地实景照片。
- 按地区和兴趣组合筛选去处；地点卡提供出发关键词、适合时段和不含交通的建议停留时间，并提供两条可选的短路线。
- 16 颗泡泡：等船、喝茶、树荫、过早等，移动端 4 列、桌面端 8 列；戳破后可再次查看。
- 场景收藏、今天的口袋、从收藏再次打开详情及单条移出，本地持久化。
- 原创灰蓝色胖鲸鱼 SVG，点击后闭眼并显示 Zzz；声音默认关闭，主动打开后实时合成轻微气泡声。
- 撕烦恼：六条预设与自由输入，撕纸反馈，最近五条克制回复。
- 四种环境底噪：轮渡、过早摊、茶馆、家属院，Web Audio 实时合成；默认关闭、单场景播放，停止或切换时淡出 1.2 秒。
- 下午存根：120 字内的便签、本地日期和随机底噪标签；恢复上一张便签，导出 1080×1350 PNG。
- 三次泡泡或撕纸互动后，小鲸鱼呈金色，点击领取随机遛弯借口；不显示任务进度。
- 320px 起响应式、原生模态框、键盘焦点、减少动态效果设置。

当前完成范围与验证边界见 [验收清单](docs/ROADMAP.md)。

## 配置说明
无环境变量和外部服务。泡泡场景、地区分类和出行建议在 `src/state.js`，底噪标签和烦恼预设在 `src/journal-state.js`。收藏保存在 `wuhan-bu-ji-v1`，便签保存在 `wuhan-bu-ji-note-v1`，均不上传；筛选和烦恼仅在当前页面会话中保留。再次保存便签会替换上一张，导出始终使用已保存版本。声音开关每次打开页面均为关闭。地点资料来源与维护边界见 [地点说明](docs/PLACES.md)。

## 项目结构
`index.html` 页面；`style.css` 原有视觉；`chapters.css` 新章节视觉；`src/` 分模块交互、存储、音频与导出；`assets/` 本地素材；`tests/` 单元与浏览器测试；`tools/check.mjs` 语法和资源校验；`docs/` 契约、素材和验收。

## 测试
Node.js 22+ 执行 `npm test`；`npm run build` 执行全部源码语法与页面本地资源路径校验。本项目无需打包，源码即静态发布内容。详见 [测试说明](docs/TESTING.md)。
